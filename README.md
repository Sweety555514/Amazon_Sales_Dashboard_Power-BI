

# Amazon Sales & Order Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Amazon Sales & Order Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides a clear overview of sales and order performance by analyzing important business areas such as **sales amount, courier status, product categories, fulfillment methods, product sizes, and state-wise shipping**.

The main objective of this project is to transform raw e-commerce data into meaningful visual insights that can help understand sales performance, order movement, product demand, and geographical distribution.

---

## 🎯 Project Objective

The dashboard was created to answer important business questions such as:

- How much sales were generated?
- What is the current status of orders?
- Which product categories have the highest demand?
- Which fulfillment method is used more?
- Which sizes are most popular?
- Which states receive the highest number of shipments?
- How are orders distributed between different fulfillment partners?

---

## 📌 Key KPIs & Analysis

### 💰 Sales Amount
The dashboard shows a total **Sales Amount of 11.58M** for the selected date period.

### 🚚 Courier Status

The order status is divided into:

- **Shipped:** 16.98K
- **On the Way:** 1.24K
- **Cancelled:** 0.85K
- **Unshipped:** 0.77K

Shipped orders represent the largest share of the displayed courier status.

### 👕 Top 5 Product Categories

The dashboard highlights the following categories:

- **T-shirt:** 8.1K
- **Trousers:** 1.6K
- **Wallet:** 0.2K
- **Socks:** 0.1K
- **Shoes:** 0.0K

T-shirts have significantly higher demand compared with the other displayed categories.

### 📦 Fulfilled By

Orders are distributed between:

- **Ekart:** 13K
- **Easy Ship:** 7K

Ekart handles a larger share of the displayed orders.

### 🚚 Fulfillment Type

The dashboard compares:

- **Amazon:** 13K
- **Merchant:** 7K

Amazon fulfillment has the higher order count in the analyzed data.

### 📏 Top 5 Sizes

The most frequently ordered sizes shown are:

- **M:** 3.6K
- **XL:** 3.3K
- **XXL:** 2.8K
- **S:** 2.7K
- **XS:** 1.8K

M is the most popular size among the displayed size categories.

### 🗺️ Ship-State Analysis

The dashboard shows the top shipping states based on order count:

- **Maharashtra:** 3.3K
- **Karnataka:** 2.5K
- **Telangana:** 1.8K
- **Uttar Pradesh:** 1.7K
- **Tamil Nadu:** 1.7K
- **Delhi:** 1.1K
- **Kerala:** 1.0K
- **West Bengal:** 0.9K
- **Andhra Pradesh:** 0.8K
- **Gujarat:** 0.7K

Maharashtra has the highest number of shipments among the displayed states.

---

## 🔍 Key Insights

- The dashboard reports **11.58M in sales** for the selected date range.
- **Shipped orders (16.98K)** are much higher than cancelled, unshipped, and in-transit orders.
- **T-shirts are the dominant product category**, with 8.1K orders in the displayed analysis.
- **Ekart** has a higher fulfillment count than Easy Ship.
- **Amazon fulfillment** is higher than Merchant fulfillment.
- **M size** has the highest order count among the displayed sizes.
- **Maharashtra** leads the displayed states in shipment volume, followed by Karnataka.
- The dashboard helps identify product demand and high-volume shipping regions at a glance.
